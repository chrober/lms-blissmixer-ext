BLISSMIXEREXT_LEARNED_BLEND
	EN	Learned matrix influence

BLISSMIXEREXT_LEARNED_BLEND_DESC
	EN	For multiple adaptive-weighting seeds, controls how strongly the learned matrix influences similarity. 0 is variance only; 100 is learned matrix only. A single seed uses the learned matrix directly.

BLISSMIXEREXT_PLAYCOUNT_INFLUENCE
	EN	Play-count influence

BLISSMIXEREXT_PLAYCOUNT_INFLUENCE_DESC
	EN	Controls how listening history reranks Bliss candidates. Negative values prefer less-played tracks, 0 disables reranking, and positive values prefer frequently played tracks. Greater absolute values consider a larger candidate pool; Last.fm and play count share the same pool when both are active.

BLISSMIXEREXT_PLAYCOUNT_INFLUENCE_UNAVAILABLE
	EN	This setting requires Lyrion listening statistics. They are disabled when the server is started with --nostatistics.
